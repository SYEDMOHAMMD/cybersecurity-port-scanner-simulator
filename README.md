# Cybersecurity Port Scanner Simulator

A browser-based cybersecurity visualization project that simulates TCP port scanning and demonstrates how open ports relate to potential security risks. Built for learning core networking concepts and basic security analysis.



## Overview

This project simulates how a basic port scanner works by iterating through a range of ports and displaying "open ports" in a terminal-style interface. It is designed for educational purposes to help understand network exposure, service mapping, and basic vulnerability awareness.

The tool also integrates Claude AI to generate a high-level security assessment based on the simulated scan results.



## Features

- Simulated TCP port scanning across a configurable port range
- Real-time terminal-style scanning interface
- Service mapping for common ports (SSH, HTTP, FTP, etc.)
- Risk classification for open ports (Low / Medium / High)
- AI-generated security summary using Claude API
- Clean cybersecurity-themed UI inspired by terminal tools



## Key Learning Concepts

- Networking fundamentals (ports, services, exposure)
- Basic understanding of TCP connections
- Common vulnerable services and attack surfaces
- Frontend development using HTML, CSS, and JavaScript
- API integration (Anthropic Claude API)
- Event-driven programming in the browser

---

## Important Note

This is a **simulation-based educational project** and does not perform real network scanning.  
It is intended to demonstrate concepts of port scanning and security analysis in a safe browser environment.



## How to Run

1. Download or clone the repository
2. Open `port_scanner.html` in any modern browser (Chrome, Edge, Firefox)
3. Enter a target host and port range
4. Click "Scan" to start simulation

> Note: AI analysis requires a valid Anthropic API key to function.



## Tech Stack

- HTML5
- CSS3 (custom dark terminal UI)
- Vanilla JavaScript
- Claude AI (Anthropic Messages API)
